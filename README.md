# HedgeOS 3.0  
A lightweight web‑based operating system built with Puter.js.

## ✨ Features  
- Desktop, windows, and file manager  
- EXE launcher (via integrated web emulator)  
- APK launcher (via browser‑based Android emulator)  
- Basic apps: editor, viewer, terminal  

## 🚀 Run Locally  
```
npm install
npm run dev
```

## 📦 File Support  
- `.exe` → opens in EXE emulator  
- `.apk` → opens in Android emulator  
- Common text/image formats supported
